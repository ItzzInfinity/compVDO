# Manual Tasks (require your action)  (aliased as `manualTasks.md`)

Everything that needs an account, an API key, a console click, a device, or a
password lives here. The agent **cannot** do these and must never retry them —
it files an `M<n>` and moves on to work that isn't blocked.

Roadmap items waiting on one of these are marked `[M]` and name the number.

### M1 — Supply real phone clips for the trial  (unblocks 1.16, 2.8)
- [x] 1. Copy 3–5 videos straight off your phone into a folder, e.g.
      `~/Videos/compvdo-samples/`. Do **not** let a messaging app re-compress
      them — copy over USB or MTP.
- [x] 2. Include at least one **portrait** clip (this is what catches rotation
      bugs) and one that is not MP4 if you have one.
- [x] 3. Tell me the folder path.
- Until then, Phase 1 is tested against synthetic clips generated by ffmpeg,
  which prove correctness but not real-world compression ratios.

### M2 — Windows machine for Phase 3  (unblocks 3.4, 3.5)

- [ ] 2. Confirm whether you want a single `.exe` or a folder build

### M3 — Android build environment for Phase 4  (unblocks 4.6)
- [ ] 1. Android Studio installed, or a JDK 17 + command-line SDK tools.
- [ ] 2. A physical device with USB debugging on (emulators have unreliable
      hardware video encoders — this matters for this app specifically).
- [ ] 3. Minimum Android version you want to support (Media3 Transformer is
      solid from API 26; API 33+ gives the nicer photo-picker permission).
- Not needed until Phases 1–3 are done.

      real lossless as an `archive` mode. Say the word if you want it the other
      way round.
- [ ] 2. Anything here you want dropped from v1 to ship sooner.
